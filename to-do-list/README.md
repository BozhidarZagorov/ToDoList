ToDoList App 📝🐈

A modern animated Todo application built with Angular and Firebase.

Features a glassmorphism UI, drag & drop task management, task details modals, authentication, animated pixel cats, and real-time Firebase syncing.

Features ✨
Firebase Authentication
Real-time Firestore database
Add / Edit / Delete Todos
Task statuses:
Not Started
In Progress
Completed
Drag & Drop task movement
Task detail modal
Animated pixel cats across the screen 🐈
Sticky navigation bar
Route-based Angular architecture

Tech Stack ⚙️
Angular
TypeScript
SCSS
Firebase
Angular CDK Drag & Drop
RxJS

Animated Cats 🐾

The app includes animated pixel-art cats using sprite sheet animations with CSS keyframes.

Cats persist globally across routes and are rendered behind the UI for a playful desktop-pet effect.
